How it works

No subscription, no app store, no data deal. The agent lives on your machine and talks to you where you already are.

Get a laptop and Hermes

Any laptop from the last several years works. Hermes Agent is the free software underneath; the install guide walks you through it.

Add the agent profile

Copy in the specialist skills, run the one-command folder setup, and have your first chat to build your family or personal profile.

Bring in the people

Connect a WhatsApp group (or Telegram): everyone can talk to the team, voice notes included. Optional check-ins keep it ticking.

Safety, plainly

When things get hard, the agent steps back.

A support tool earns its place in a family by what it does in the worst moments, not the best ones. Here is exactly how this one behaves, so you can judge it yourself.

It stops, and it cares

In a hard moment, self-harm, abuse, harm or a medical emergency, the agent drops its normal work entirely. No routines, no check-ins, no to-do lists. It responds with care, in plain words, and turns to real help.

A real person takes it from there

The agent is an assistant, never a counsellor, and it never pretends otherwise. Danger comes first and plainly: emergency services and a trusted adult, right now. Every hard moment ends with a human named, you, your GP, or a crisis line.

Local help, checked before it matters

At setup it asks where you are and builds a short list of local support for your area: autism and ADHD organisations, parent and carer lines, crisis services. Every number is verified when the list is built, and checked again each quarter.

The list, the crisis plan and everything about your family live on your machine, like the rest of the agent. In complete confidence, ask it any time: "what would you do if we were in crisis?"

Questions people actually ask

Is this really free?
Yes. Both agent profiles are free to download and free to use for families and individuals, with credit. The Hermes software underneath is open source. There is no subscription and no data deal; the whole point is putting real support within reach.
What do I need to run it?
A laptop or desktop from the last several years, about 30 minutes for setup, and a free model provider account (or local models for fully offline running). Not sure what your computer can run? canirun.ai checks your machine and shows the local models that fit. The install guide covers both paths step by step.
Is it therapy? Can it diagnose my child?
No, and it will tell you so plainly. It supports the family: strategies, schedules, advocacy, tracking, conversations. Diagnosis stays with clinicians, therapy stays with therapists, and crises go straight to humans with real phone numbers.
What happens if our child is in crisis?
The agent stops everything else, responds with care, and points to real help: emergency services first where danger is immediate, then the family's own verified list of local crisis lines built during setup. It is an assistant, never a counsellor, and it never leaves a hard moment without handing the matter to a real person. The full protocol is in the open repos.
Where does our family's information go?
Onto your own machine, in plain files you can read. If you use an online model provider, chat text goes to that provider; if you run local models, nothing leaves the machine at all. Optional calendar and mail connections are off by default and read-first when on.
Which agent is right for me?
Both are ready now. The Family Agent is for families raising neurodiverse children; the Individual Agent is for a neurodivergent adult. Some people run both. Same setup underneath, both free, both private.
