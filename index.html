How it works

No subscription, no app store, no data deal. The agent lives on your machine and talks to you where your family already lives.

Get a laptop and Hermes

Any laptop from the last several years works. Hermes Agent is the free software underneath; the install guide walks you through it.

Add the agent profile

Copy in the twelve specialist skills, run the one-command family folder setup, and have your first chat with the Family Navigator to build your family profile.

Bring in the family group

Connect the agent to a WhatsApp group (or Telegram): everyone in the family can talk to the team, voice notes included. Optional check-ins keep it ticking.

Prefer staying offline? The whole thing runs with local models and local voice, with nothing leaving your machine.

Questions people actually ask

Is this really free?
Yes. Both agent profiles are free to download and free to use for families and individuals, with credit. The Hermes software underneath is open source. There is no subscription and no data deal; the whole point is putting real support within reach.
What do I need to run it?
A laptop or desktop from the last several years, about 30 minutes for setup, and a free model provider account (or local models for fully offline running). The install guide covers both paths step by step.
Is it therapy? Can it diagnose my child?
No, and it will tell you so plainly. It supports the family: strategies, schedules, advocacy, tracking, conversations. Diagnosis stays with clinicians, therapy stays with therapists, and crises go straight to humans with real phone numbers.
Where does our family's information go?
Onto your own machine, in plain files you can read. If you use a cloud model, chat text goes to that provider; if you use local models, nothing leaves the machine at all. Optional calendar and mail connections are off by default and read-first when on.
Which agent is right for me?
Both are ready now. The Family Agent is for families raising neurodiverse children; the Individual Agent is for a neurodivergent adult. Some people run both. Same setup underneath, both free, both private.
How can I help?
Try it with your family and tell us what breaks. Share it with a family or a neurodivergent adult who needs it. Say hello below, we answer.
